Reference for **humanish 0.110.1**. Run `npx humanish --version` to check your installation, or `npx humanish <command> --help` for its exact flags.

Start with the [quickstart](/docs). The examples below use the installed `humanish` binary; prefix them with `npx` from your project if it is not on your PATH.

`--json` returns machine-readable responses where supported. `tui` requires a human terminal and refuses detected agent sessions, including agents with a TTY. See [TUI refusals and read-only JSON alternatives](/docs/review-surfaces#for-coding-agents-and-scripts).

## humanish run

Run a study, as a dry run or with live participants. This is the everyday command.

```text
humanish run [options] [study]
```

| Argument | Description |
| --- | --- |
| `study` | Optional study id or .yaml path. |

| Option | Description |
| --- | --- |
| `--dry-run` | Do a dry run: a synthetic run with no browser, keys or provider spend. |
| `--open` | Open the Observer in the default browser. |
| `--no-open` | Render without opening a browser. |
| `--detach` | Render/open once and exit without an attached watch server. |
| `--port <port>` | Port to listen on at 127.0.0.1. (default: a free port) |
| `--count <count>` | Override the participant count of a preview or computer-use study, or of the synthetic run without a study. |
| `--rerun-failed-from <run>` | Computer-use studies only: start a new run for the failed participants of a prior run. |
| `--participants <ids>` | With --rerun-failed-from: comma-separated ids of the participants to rerun. The study's participants decide who takes part; ids are their id, or lane-01, lane-02, … by position. |
| `--scorer <path>` | Score with this .mjs module, a path inside the repo, in place of review.scorer.ref. It runs as code, so review it first. Terminal, computer-use and shared-world studies only. |
| `--cwd <path>` | Project directory. (default: ".") |
| `--dotenv <path>` | Load unset variables from this dotenv file. Values are never printed or saved. |
| `--run-id <id>` | Explicit run id for deterministic fixture tests; refused when that run already exists. |
| `--json` | Print a machine-readable JSON response. |
| `-h, --help` | Show help for this command. |

## humanish migrate

Convert humanish.lab.v2 study files to humanish.study.v3. A file under a labs/ directory moves to the matching studies/ directory; any other file is rewritten in place. An original that a failure leaves out of place is kept as &lt;name&gt;.v2.bak. Pass the files to convert; without any, the six study directories are scanned. | `--inbox-port <port>` | Also serve a read-only inbox listener on 0.0.0.0:&lt;port&gt;, so a persona on another machine can open /inbox. Without it the catch stays loopback-only. |

## humanish reclaim

Kill an interrupted run's sandboxes: the exact ids journaled in its sandbox-receipts.ndjson, and any sandbox E2B lists with this run's owner tags (a sandbox whose id never reached a receipt). It lists only sandboxes that match every tag of this run. --check asks E2B whether each still exists and kills nothing. Needs E2B_API_KEY in the environment or in --dotenv.

```text
humanish reclaim [options]
```

| Option | Description |
| --- | --- |
| `--cwd <path>` | Project directory. (default: ".") |
| `--run <id>` | Run id, or latest. (default: "latest") |
| `--preflight` | Reclaim sandboxes left by interrupted `humanish study check` probes (journaled in .humanish/preflight) instead of a run's. |
| `--check` | Ask E2B whether each sandbox still exists; kill nothing and write nothing. Exits 0 only when all are gone. |
| `--dotenv <path>` | Load unset variables from this dotenv file. Values are never printed or saved. |
| `--json` | Print a machine-readable JSON response. |
| `-h, --help` | Show help for this command. |

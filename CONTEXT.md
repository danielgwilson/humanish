# Glossary

One word per concept. Docs, CLI output and new code use the term in the first column. Older
schema fields keep their names, because `humanish.lab.v2` and `humanish.run-bundle.v1` are
contracts; the last column maps them.

| Term        | Meaning                                                                                                                                                                                              | Also appears as                                                                                         |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| study       | Everything one `humanish run <lab>` produces: participants, evidence and analysis. The user-facing word for a run.                                                                                   | run                                                                                                     |
| lab         | A YAML manifest that declares a study: `humanish/labs/<id>.yaml`, schema `humanish.lab.v2`.                                                                                                          | lab config                                                                                              |
| run         | One execution on disk: `.humanish/runs/<runId>/`, with `run.json` (`humanish.run-bundle.v1`) as the source of truth.                                                                                 | bundle, run bundle                                                                                      |
| participant | One simulated person, or agent, taking part in a study.                                                                                                                                              | lane (`actors[0].lanes[]`), simulation (`simulations[]`, `simCount`), seat and role (shared-world), sim |
| persona     | Who a participant is: traits, background, device. `humanish/personas/<id>.yaml`.                                                                                                                     |                                                                                                         |
| scenario    | What a participant is asked to do. `humanish/scenarios/<id>.yaml`.                                                                                                                                   | mission, task                                                                                           |
| subject     | The product under study, declared by `subject.source`: `clone`, `app-url`, `local-tree`, `terminal-product`, `desktop-cli`, `local-app` or `this-repo`.                                              | target app                                                                                              |
| actor       | The model or program that drives a participant, declared by `actors[0].type`, e.g. `openai-computer-use`, `local-agent`, `scripted-browser`, `codex-exec`. `src/actors/registry.ts` lists all seven. | brain                                                                                                   |
| route       | The execution path `selectLabBackend` picks for a lab: `cua`, `scripted`, `terminal`, `shared-world` or `concurrent-shared-world`.                                                                   | backend                                                                                                 |
| substrate   | Where a participant's desktop or shell runs: a hosted E2B sandbox or a local VM (Firecracker on Linux, Lima on macOS).                                                                               | runtime                                                                                                 |
| topology    | Whether participants share one instance of the subject. `per-lane-worlds` (the default) gives each its own; `shared-world` puts all of them in one.                                                  | world                                                                                                   |
| stream      | A participant's live or recorded view in the Observer.                                                                                                                                               |                                                                                                         |
| Observer    | The single-file review page built from `observer/observer-data.json` (`humanish.observer-data.v1`).                                                                                                  |                                                                                                         |
| finding     | A result of study analysis, with citations to evidence in the run.                                                                                                                                   | observation                                                                                             |
| evidence    | Files a run keeps: screenshots, traces, transcripts, recordings. `verify` checks them and grades share-safety.                                                                                       | receipts                                                                                                |

# Coverage Map

This map keeps Humanish honest as its own first target app.

## In Scope For V0 Dogfood

- CLI help and command discoverability.
- Safe `init` preview and applied layout.
- `doctor` readiness over committed `humanish/` source.
- Synthetic dry-run bundle generation from committed dogfood files.
- `watch` one-command self-run, Observer render, browser open, and shell
  watch.
- `verify`, `review`, and `runs` output.
- Public-safe `feedback issue` Markdown.
- Terminal-lane self-studies: `labs/first-contact.yaml` and `labs/last-mile.yaml`
  run a `codex-exec` agent against humanish in an E2B sandbox.
- Desktop self-study of the TUI: `labs/tui-self-study.yaml`.
- Release and publish gates.

## Explicitly Deferred

- GitHub mutation, production data, and private artifacts in any dogfood run.

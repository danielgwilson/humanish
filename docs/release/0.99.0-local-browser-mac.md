# 0.99.0 — Local browser studies on Apple Silicon Macs

Explicit local browser labs now run on M3-or-newer Macs through Lima/VZ and
ARM64 Firecracker desktops. The same scheduler, Observer recordings and automatic
analysis used on Linux remain in place. Codex and its file-backed ChatGPT login
stay on the Mac; E2B and OpenAI API keys are unnecessary for the account route.
Inference remains remote and uses account quota, with unknown dollar cost.

Install Lima 2.2 or newer and use native ARM64 Node. `humanish runtime setup`
creates a dedicated Linux host, installs Docker there and downloads the pinned
ARM64 image with size/hash verification. Docker Desktop is not required. The
first live local run can perform the same setup; status and doctor remain
read-only. See the [setup guide](../architecture/local-browser-runtime.md).

The host mounts no Mac directories. Standard OpenSSH forwards browser control
and the selected loopback app port. Each participant retains its own VM and
private state volume. Closing a study removes participant resources and keeps
the reusable Lima host; `limactl stop humanish-runtime` stops it when idle.
Native Codex discovery also handles hoisted npm packages correctly.

An installed candidate on an M5 Max passed first-attempt public runtime setup,
cache reuse and a two-participant study with distinct app-side saves, overlapping
sessions, verified recordings and complete automatic analysis. Established Mac
desktop close/cancel/controller-death cleanup passed. Focused real Linux checks
of the shared lifecycle cover cancellation after creation and after start but before guest readiness, plus
recovery when Docker creates a container but its reply is lost; Lima cleanup has
separate regression coverage. These are scoped observations, not a capacity or
cold-install performance benchmark.

This remains browser-only with explicit lab configuration. Local inboxes,
camera/microphone support and simpler default onboarding follow separately.
Larger cohorts, smaller/Intel Macs, sleep/wake, keychain-only login, full-study
cancellation and forced controller death during startup remain unqualified.
Existing Linux and hosted labs retain their configuration and providers.

# Humanish 0.91.1

Study cost summaries include retained analysis attempts alongside participant
and desktop estimates. Reusing a saved analysis does not add another charge;
separate retries do. Missing prices and incomplete histories remain explicit.
The existing stats JSON fields keep their original participant-and-desktop
meaning; additive cost fields provide the combined retained estimate.

Finding previews prefer directly cited visual evidence over nearby context
captures. Selection is deterministic, but does not establish that the chosen
image is the best illustration of an issue. Exact source links and reviewer
corrections remain available.

Report qualifications are easier to scan, with the full limitations available
through a disclosure. This changes presentation without changing saved analysis
or participant feedback.

Final hosted Chromium geometry follows the active page after tab changes.
Valid CSS viewport measurements survive missing page-reported outer-window
bounds. Missing measurements remain missing; physical screen dimensions never
substitute for the page viewport.

The own-app guide now describes the hosted reachability probe and its desktop
cost. Starter comments document the existing opt-in mobile emulation settings.

See the [cost accounting contract](../contracts/study-costs.md) and the
[verification receipt](https://github.com/danielgwilson/humanish/blob/main/docs/goals/computer-use-actor/receipts/study-review-polish-2026-09-15.md)
for the methods and limits of these checks.

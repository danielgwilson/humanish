# 0.100.1 — Continuing participant conversations

Local Codex participants now keep one conversation for their entire study,
including closing feedback. Previously, each screenshot started a new thread
with only eight turns of summarized history. Earlier observations, actions and
participant context now remain in the Codex conversation, with Codex managing
context compaction.

Each participant has its own process and thread. The existing browser executor,
recordings and separate post-run analyst are preserved. Request deadlines still
apply per turn; thread-cumulative token usage is converted to per-turn receipts.
An interrupted or failed participant closes its session rather than silently
restarting with empty memory. Dollar usage remains unknown for account-backed
inference.

Existing E2B/API and hosted Codex participants already continued their
conversations and retain those paths. Older Observer recordings remain readable.
No setup changes or Firecracker image downloads are required for this fix.

# 0.104.2 — Recording timestamp precision

Desktop video encoding now uses the microsecond time base supplied by capture.
The previous encoder default rounded timestamps to the nominal 15 fps grid and
dropped some distinct captures taken close together after an input stall. The
shared local/E2B recipe specifies the encoder time base and variable-frame-rate
output; the capture rate, audio
settings, resource limits and metadata clock remain unchanged.

In a controlled one-second capture interruption, the previous recipe received
96 captures and retained 82 output frames. The correction retained all 96 with
timestamps within 1 ms of their input times, while preserving the missing interval.
The H.264 profile and level remained unchanged. Explicit variable-frame-rate
output also prevents older FFmpeg defaults from synthesizing duplicate frames
to fill a gap. No original recording is rewritten.

This is a timestamp-fidelity correction, not a fix for every guest execution stall.
The #854 follow-up reproduced browser pauses and guest CPU contention, without
establishing one offending process. A recorded frame can correctly show an
unchanged screen during an application pause. Separate follow-up recordings
retained every paired event but measured audio 64–147 ms before visible flashes;
source delivery and recording precision must be distinguished before attributing
that offset. The earlier one-frame timing result was a single-run measurement,
not a universal guarantee. #854 remains open for those limits.

Final local interruption controls retained 94/94 screen-only and 96/96 mixed
input frames, with no output frames inside the interruption. E2B’s FFmpeg 4.4
retained 106/106 screen-only and 105/105 mixed input frames, each within 1 ms
of input timestamps. Browser decoding and seeking passed, and externally stopped
capture still returned partial metadata with recorder/audio cleanup. A local VM
retained ten complete paired events through 60 seconds, within one video frame
in that run; this does not close the separate intermittent-stall investigation.

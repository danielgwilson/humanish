# 0.105.0: Rich participant backgrounds

Personas can carry an optional multiline `background` into autonomous browser and
terminal studies. It preserves paragraphs up to 32,768 UTF-8 bytes; invalid or
oversized backgrounds stop execution instead of silently losing context.

`humanish lab inspect <lab> --json` includes the compiled persona section and
resolution warnings. Supported autonomous traces retain that section with its
compiler version and digests. Participants details show the recorded context
separately from the assigned task and any recorded context hints. Older bundles
remain readable and explicitly lack a recorded background.

## Behavior and compatibility

- Legacy profiles retain medium patience/skill defaults. Rich profiles receive
  only explicitly declared traits, with a reminder to review prose conflicts.
- Missing persona files and unsupported fields warn. `background` is supported;
  `backstory` is not an alias. Legacy short fields still have their existing limits,
  now with diagnostics when shortened or omitted.
- Absent accessibility needs such as `none_declared` no longer become instructions.
  `keyboard_first` now describes a preference permitting pointer fallback;
  `keyboard_only` describes an exclusive requirement. Neither is mechanically
  enforced by these prompt instructions.
- Technical confidence no longer dictates one recovery attempt or requires
  confusion narration. Inbox context no longer prohibits stopping while waiting,
  and no-progress hints no longer suggest UI controls to try.
- Setup guidance distinguishes autonomous goal-based studies from scripted
  regression checks. Hidden task-success criteria remain outside participant
  prompts.

Known values and recognized secret/path patterns are scrubbed from retained
briefs. This does not detect all personal information. Keep committed profiles
synthetic or de-identified and review any evidence before sharing it.

## Evidence limits

A retained brief proves which persona context was supplied, not that its behavior
was faithful. Configuration tests cover long trailing facts, diagnostics, hidden
criteria and compatibility. Behavioral qualification uses independently recorded
app choices and preserves incomplete outcomes. No human-population accuracy,
adoption estimate or generalized persona-fidelity claim is made by this release.

In a 12-session synthetic planning pilot, six candidate sessions chose visibility
consistent with their privacy/outreach background. The previous release ignored
that field and selected public access in all six sessions. Reversing option order
did not change this result. This measures enabling relevant context on one app,
not an equal-information prompting comparison. All original attempts were kept.
The fixture lacked distribution controls: saving was observed, but the candidate
correctly left the broader distribution goal incomplete in all six sessions.
Four follow-up save-only controls completed, including two irrelevant biographies.

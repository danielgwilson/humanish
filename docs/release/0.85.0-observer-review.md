# Humanish 0.85.0: watch and review complete screens

Observer now shows portrait and desktop captures at their original proportions,
with equal-height grid previews and a compact caption below each screen. Live
labels and controls leave the captured pixels clear. A stable Info button opens
participant details, labeled Pin/Compare actions and recorded notices.

Run activity, viewing mode and evidence freshness are distinct. Finished studies
say they are finished; failed updates preserve the last evidence and offer retry.
Seeking, keyboard controls, moment links and refresh agree about the displayed
capture. Paused replay stays on its selected frame as new evidence arrives.

The review tools include:

- elapsed-time playback, capture-gap labels, Skip waits and action/finding navigation;
- fit, actual size, zoom/pan, fullscreen and a hideable/resizable inspector;
- copyable moment links, original-frame inspection and local saved moments;
- preview size, filtering, pinning, monitoring and reachable participant pages;
- participant and cross-run comparison with explicit capture age and missing coverage;
- consistent icons, keyboard hints, explicit popover dismissal and larger touch targets.

`observe` and the built TUI open existing evidence through a local viewer. Live
desktop access remains owned by the attached process; opening an existing study
cannot recover another process's credentials. Offline exports keep the current
renderer and saved images without runtime desktop authority. The
[Observer review guide](../architecture/observer-review.md) explains these paths.

## Updating

Install this version using your usual package manager. For a global installation:

```bash
npm install -g humanish@0.85.0
humanish --version
humanish observe --run RUN
```

Run the last command from the workspace containing the existing study. Previously
generated HTML embeds its viewer: reopen the run with the updated CLI, or
regenerate its HTML export, to get the new interface.

## Verification and limits

The implementation was exercised with five hosted two-participant studies and
140 retained screenshots. A separate check opened all 28 frames through observe,
the built headed TUI and HTML export: 84 of 84 opens passed. The
[implementation receipt](https://github.com/danielgwilson/humanish/blob/main/docs/goals/observer-qol/receipts/2026-09-08-observer-review.md)
distinguishes failed probes, accepted runs and cleanup evidence.

Regression coverage includes 156 Observer tests, 33 production-artifact browser
scenarios and 15 iframe/artifact isolation checks. Browser acceptance covers
Chromium on Linux, including touch emulation; physical devices and other engines
remain unverified. Screenshot replay remains sparse evidence, without a
continuous video track or guaranteed before/after capture for every action.
The pre-existing source-checkout TUI loader limitation remains; the built CLI
is the tested installation path.

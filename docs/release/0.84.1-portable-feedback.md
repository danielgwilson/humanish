# Humanish 0.84.1: feedback commands work in exported workspaces

Feedback acceptance commands now call the installed `humanish` CLI directly.
They work from a standalone exported evidence workspace without a package
manifest or repository script:

```bash
humanish verify --run RUN --json
humanish watch --run RUN --no-open
```

Run them from the directory containing `.humanish/`, with the CLI on `PATH`.
The watch command serves the Observer until stopped. These commands do not
download a different package version.

Redrafting feedback from recognized first-party candidates also updates exact
legacy command templates. Custom acceptance instructions and all original
candidate evidence and receipts remain unchanged. Unusual run IDs are quoted
for shell use. The [feedback contract](../contracts/feedback.md) describes the
compatibility boundary.

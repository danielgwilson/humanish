# 0001: The run bundle is the source of truth

Accepted.

## Context

Several surfaces read a finished or running study: the Observer, `humanish tui`, `serve`,
`export`, feedback drafts and study analysis. Each of them wants a smaller, faster view than the
full bundle, and a view that can drift from the evidence would let a surface show a result the
evidence does not support.

## Decision

`.humanish/runs/<runId>/run.json` (`humanish.run-bundle.v1`) and the artifact files it lists are
the evidence. Everything else is a projection rebuilt from them:

- `observer/observer-data.json` is regenerated by `export` and by every Observer render.
- `status.json` (`humanish.run-status.v1`) is a liveness index. When it disagrees with `run.json`,
  `run.json` wins, and `verify` never reads it.
- Analysis findings cite turns and artifacts in the bundle.

## Consequences

- Bundle schema fields are a public contract. `docs/contracts/run-bundle.md` documents them, and
  renaming one needs a new schema version.
- A projection can be deleted and rebuilt without losing evidence.
- Surfaces cannot add facts of their own; a new fact goes into the bundle first.

## Enforced by

- `verifyRun` in `src/run/run.ts`, which grades only the bundle and its artifacts.
- `tests/observer-data-contract.test.ts` for the Observer projection.

# Homepage preview / live-study clarity — 2026-09-05

Three live synthetic newcomer sessions read humanish.dev and its new docs, looking for the
smallest useful study on their own app. They used hosted browsers; the mission did not ask
them to install packages, enter credentials, or execute an app study.
The browser-study instrument was pinned to harness commit `09ede74`, matching the earlier
comparison cohort; later merged harness changes were not introduced between cohorts.

Kept runs:

- `cua-2026-09-05T01-32-47-159Z-0b3d1911`
- `cua-2026-09-05T01-34-10-904Z-ff5e7d60`
- `cua-2026-09-05T01-35-43-595Z-95387598`

All three described both the live own-app path and the keyless evidence preview correctly.
All three also reported hesitating over two points:

1. The homepage's shorter install/init/watch sequence appeared inconsistent with the live
   docs' desktop peer, provider keys, and named lab. The homepage sequence is the preview.
2. The heading “Run a real participant” initially sounded like a human tester. The study
   uses a synthetic participant in a real app.

The resulting copy change labels the homepage console as a keyless evidence preview, gives
it a direct live-study link, makes the command ledger's live lab argument explicit, and
uses “Run a live study” in the quickstart. The closing command line now describes generated
preview evidence instead of suggesting a persona observed the app.

These are three exploratory runs of the same newcomer mission, not a human acceptance study
or a population estimate. One session lacked browser-state instrumentation and used a smaller
browser window than requested; screenshot evidence and the participant's report remained.
One report questioned the September 2026 receipt dates. That concern was not corroborated;
it is treated as model temporal confusion, not counted as a confirmed website defect.
This receipt records the finding that motivated the edit. It does not claim that the revised
copy has improved comprehension; a further study would be needed for that claim.

# History

Dated goal packets, plans and the 2026-06 roadmap. Each page records what was planned or decided
when it was written. None of them is maintained, so a page may name files, commands or limits that
have since changed, and `docs:check` skips this folder. [status.md](../status.md) says what ships
today, [CHANGELOG.md](../../CHANGELOG.md) says what each version changed, and `git log` dates every
page. Study records that current pages cite live in [evidence/](../evidence/README.md).
